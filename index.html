On-demand computers for AI agents

Spin up a clean, isolated machine for each agent run or eval, then throw it away. Prices were checked on each vendor's pricing page on 14 Oct 2026.

Short version

🥇 E2B is the industry default: one SDK call per sandbox, about $0.17/hr, and a full Linux desktop for computer-use agents.

💸 Daytona costs the same and gives $200 in free credit, plus Windows VMs and GPUs.

💤 If your agent mostly waits on LLM calls, Cloudflare or Vercel is cheapest, because they bill only for CPU time actually used.

The options

E2B Industry default

$0.17 / hr · 2 vCPU, 4 GiB
  • Billing: per second ($0.000014 per vCPU-second, $0.0000045 per GiB-second)
  • Free: $100 one-time credit. Pro is $150/mo.
  • Max session: 1 h on the free plan, 24 h on Pro
  • Computer use: E2B Desktop (open source) gives a Linux desktop with mouse, keyboard, screenshot and screen-stream APIs

Daytona Best value

$0.17 / hr · 2 vCPU, 4 GiB
  • Billing: per second. Same rates as E2B; the first 5 GiB of disk is free.
  • Free: $200 in credit, no card needed
  • Startup: under 90 ms (vendor's claim)
  • Extras: Windows VMs ($0.0858 per vCPU-hour), GPUs from $0.57/hr

Cloudflare Containers Cheapest when idle

~$0.08–0.22 / hr · 2 vCPU, 8 GiB
  • Billing: every 10 ms. CPU is charged only when used ($0.00002 per vCPU-second).
  • Free: small monthly allowance on the $5 Workers plan
  • Behavior: sleeps to zero when idle; uses the Sandbox SDK

Vercel Sandbox Eval-friendly

~$0.11–0.34 / hr · 2 vCPU, 4 GB
  • Billing: $0.128 per active-CPU hour and $0.0212 per GB-hour of memory
  • Free: 5 CPU-hours a month on Hobby
  • Max session: 45 min on Hobby, 24 h on Pro. Up to 10,000 sandboxes at once on Pro.
  • Official guide for running Terminal-Bench and SWE-bench evals

Modal Sandboxes Priciest

$0.24 / hr · 2 vCPU, 4 GiB
  • Billing: per second. Sandboxes cost about 3× Modal's normal CPU rate.
  • Free: $30 a month in credit
  • Pick it if: you already use Modal or need GPUs inside the sandbox

Fly Machines Raw VM

$0.09 / hr · 2 vCPU, 4 GB
  • Billing: per second while running. A stopped machine costs $0.15 per GB per month of disk.
  • Catch: a plain VM, not a sandbox SDK, so you build the agent wiring yourself
  • Pick it if: the CPU stays busy and you want the lowest price

Which one?

“I want the standard thing”E2B
“I want free credit or Windows”Daytona
“My agent mostly waits on the model”Cloudflare or Vercel
“I need GPUs in the sandbox”Modal or Daytona
“Computer use / GUI agents”E2B Desktop
“Lowest cost, busy CPU, I'll wire it myself”Fly Machines

When you don't need any of these

For one person running trusted evals, a local Docker container costs nothing and starts faster. Rented sandboxes earn their cost when you need many runs in parallel, untrusted code or prompts, or a guaranteed clean machine for every run.

Prices were checked on each vendor's pricing page on 14 Oct 2026 and may change. Not checked: Daytona's computer-use API, and browser-only services such as Browserbase and Steel.
